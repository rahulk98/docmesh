# DocMesh plugin

This directory contains the shared Codex and Claude Code plugin package for
DocMesh. Install dependencies with `uv sync --extra test`, review corpus
discovery with `scripts/setup.sh --dry-run`, then explicitly approve model
setup with `scripts/setup.sh --approve`.

The repository-level [README](../../README.md) documents the complete search,
global-edit, hook, trust-boundary, and offline workflows.
